# Physical public-source cover

Integrated source has passed focused tests and visual browser review at both required resolutions; the complete app gate remains pending. This original runtime paper cover connects the public evidence table to the authored interview tabletop. It contains the explicitly presented public source's kind, exact ID and display title only, with an explicit instruction to open the original full reader. It never fabricates document text or a finding.

The flat local SVG uses the existing tested texture lifecycle, React text escaping and no linked resources. Larger ID/title labels and opt-in mipmaps reduce static-cover aliasing; dynamic monitor atlases keep their existing no-mipmap budget. A changed source remounts the material so a stale asynchronous image cannot flash the previous ref. There is no frame loop, clock, camera, audio, subscription, transport or asset download. Clear/revocation hides it immediately. The full keyboard-accessible reader remains in the original EvidencePanel.

`PrecinctInterviewScene.evidence` carries an optional public ref/title, and `PrecinctCanvas.onInspectEvidence` opens its existing reader. PresentedEvidencePaper mounts only when the interview scene is present and evidence is non-null. The route derives this field from its already-reconciled `interviewUi.state.table.presented` and current `publicSources`, with an additional current-scope check. The pointer callback only selects the existing evidence tab and opens the existing interview modal, using the normal accepted tab event. V1 remains empty; later v2 must supply only an actual captured, currently available public presented source. It must never derive presentation from a future release or from mere selection.
