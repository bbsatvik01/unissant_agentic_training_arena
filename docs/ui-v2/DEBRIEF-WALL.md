# Published debrief wall

Original read-only SVG surface replaces the authored placeholder bars on the existing replay-room screen. It shows only the matching published session result, gated by ended public view, matching debrief-ready session ID and the route's assessment boundary. A recording is explicitly labelled as its own result, never current progress. Unscored and unscorable runs receive no made-up numeric value. Pending, changed-source and assessment states replace the material before asynchronous image decode can expose an old score.

Mount once inside the existing Canvas. Memoize `projectDebriefWall` from the current session scope, gated debrief/view and assessment state; pass the narrow resulting display only. The click uses the existing `debrief_replay` station callback. No extra camera, loop, renderer, network request or score-driven character motion. Existing source GLB, furniture, colliders and navigation remain byte-identical. Geometry and artwork are original project work.
