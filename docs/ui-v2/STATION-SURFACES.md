# Station surfaces and controller addendum

Source-only addendum to the frozen next-presentation integration. The 50-file presentation checkpoint remains unchanged. This stage adds the dialog/controller adapter, public case/recognition overlays, directional observation glazing and matching published debrief wall. It does not add crowd, patrol, navmesh, local staff voice or courtyard work.

## Ownership and behavior

- The existing native Modal installs one input-only controller adapter. It keeps native focus restoration, Escape, the expanded-monitor close callback, speech-caption target and capture status. Standard D-pad/left stick moves through visible enabled controls, with existing tab/range arrow semantics. Deliberately focused enabled buttons use their normal click and confirmation paths on a fresh A edge. B uses the existing back/close callback. Neutral-on-entry, stable-focus, hidden/unfocused suppression and no A hold-repeat prevent activation on opening/switching. Text entry, native selectors, file/download/external-window pickers and browser permission UI retain native controls; a keyboard/pointer remains needed there. Hardware acceptance is pending.
- Route Start (button 9) uses the existing pause/resume action; View (8) opens the map; right-stick press (11) cycles the live camera or toggles the existing sessionKey-scoped v2 recorded/free inspection choice. V1 camera policy stays unchanged. Route shortcuts yield to dialogs, editors and focused native controls. Free inspection retains axes 0/1 pan, axes 2/3 orbit, buttons 4/5 height and button 10 speed. No adapter advances replay/world time or becomes a second camera writer.
- Three case-board surfaces show only the supplied public metadata, server order and explicit availability. Offline dossiers and previews remain distinct. Pending/failed/missing identity and assessment states replace their display identity immediately. No unlock condition, completion, date or score is inferred.
- The recognition surface is a memory-only snapshot of the already opened canonical trophy panel. It makes no request of its own. A selected matching publication requires the actual revealed ledger and published board. Board-level not-ranked and per-row eligibility gates precede rank. Real supplied ranks/intervals are retained; no sorting or score computation is added. Closing the panel retains a labelled snapshot. Source/account/case/assessment changes invalidate it, and late old sinks are rejected. The integrated trophy child is keyed by recognition scope so a still-mounted old hook result cannot repopulate the new scope; choosing a new publication clears the old read before its request resolves.
- The debrief wall shows only the current source's ended view with a matching published debrief-ready session ID, behind centralized assessmentActive. Its narrow model is memoized in the route. Recordings are labelled as their own result; unscored/unscorable sessions get no invented number. Rewind, source changes and accepted pending assessment replace the material key before old asynchronous SVG decode can apply.
- Physical case/recognition and debrief clicks use the existing accessible station callbacks. Every new surface blocks interaction when inactive, paused or captured replay owns the scene. The accessible map/panels remain available through their existing controls.
- The observation treatment is a single original front-facing opaque metallic plane at the authored viewing opening. The observer-side back face is culled. This is stylized directional glazing, not a physical-optics or privacy/security guarantee. There is no reflection camera/render target.

## Preservation

One route session, one Canvas, one Controls camera writer and one native modal remain. Current source already includes the strict replayActive input guard, private fresh-capture capability, explicit orientation/seat handoff and the sole beforeRecording guard; this addendum does not change them. Pending/active assessment still removes the prior recording catalog entirely. Current assessment recording playback stays available through the existing player.

The authored GLB, collisions/navigation, generated contracts, backend, fixtures, package/dependency files, existing clocks and public API hooks remain unchanged. Surface artwork is locally serialized escaped SVG using the existing latest-wins texture helper, without linked resources or a new render loop. Ground-rule and no-demeanor-evidence copy remain in the existing route and accessible panels.

## Acceptance still required

No typecheck, lint, tests, build, browser, performance or hardware-controller validation has run for this addendum. The pure/DOM tests and integration regressions are authored source only. There is no unresolved source ownership conflict known after composition, but that is not semantic or visual acceptance.

After the sole CPU slot is granted: run strict types/lint and focused controller/board/debrief/route regressions, then the unchanged combined gate. Verify real WebGL at both 1440 and 1920: case-board readability and click targets; recognition unavailable/published gates without fabricated results; mirror versus viewing side and unobscured paper/screens; debrief surface alignment/readability; source/rewind/assessment clearing; native dialog focus/Escape/captions/capture status; v2 recorded/free camera ownership. Physical controller behavior requires actual hardware or an explicitly labelled emulation check, with no claimed hardware result before it occurs.
