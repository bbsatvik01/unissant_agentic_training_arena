# Four public agent-work views

Classic Office, Case Board, Playhouse and Agent Tower adapt the owner-authorized read-only TechnoMile reference. Source fingerprints and adaptation details are retained in root ATTRIBUTIONS.md and monitor-reference-checksums.sha256. No reference file, external asset, font or dependency is modified or added.

`src/lib/agent-work/model.ts` is a pure projection of the existing validated public TrialView, actual event-arrival map and canonical cursor. One WorkFrame drives all four SVG compositions, the physical screen atlas and expanded accessible views. There is no monitor-owned timer, stream, model call or reducer. Rewind uses the current public view and its actual cursor, not a final snapshot with an invented earlier time.

Accepted coach cards, deep updates, citation-validated flags and already-released evidence map to visible work. Flags require exact public transcript/record citations and the existing validator; rejected, stale, duplicated or demeanor-based flags are not resurrected. Subject animation never depends on flags or findings. Referee display receives only authoritative scoring/published status tied to the completed run, never outcome fields.

Assessment suppresses coaching before the new snapshot arrives, throughout the run and until its own published debrief. Voice suppresses text coaching. Scene, physical-screen and panel guards independently fail closed on stale practice frames. Public text is React-escaped. SVGs contain no linked images, scripts, foreignObject, CSS/SMIL clocks or remote resources.

Each thumbnail has a native named Expand button and the same readable factual record. Expanded screens use the existing modal, preserve focus and close the expansion before closing the station. All four styles share the same canonical frame. Flat fallback reflects actual event changes and explicit seeks while between-event decorative motion stays paused.
