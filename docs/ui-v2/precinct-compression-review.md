# Precinct lossless runtime compression

Verified 2026-10-15. The runtime is **3,075,764 bytes**, below the unchanged **5,242,880-byte (5 MiB)** committed-file cap. The 5,668,084-byte signage export was reduced by 2,592,320 bytes (45.7354%). Measurements are generated by `assets-src/compress_runtime.mjs` and recorded in `assets-src/compression-report.json`.

## Preservation evidence

- 116,267 triangles, 38 meshes/materials/nodes, 112 accessors and buffer views, zero textures.
- Every decoded view is byte-identical to its original view. Full decoded binary SHA-256 is identical; positions, normals and index order are exact, with no quantization, reordering, merging or simplification.
- Scene hierarchy, transforms, material definitions, material assignments, names and all other non-storage glTF fields are unchanged.
- The original editable Blender file is unchanged: 1,235,259 bytes. No Blender export, source reconstruction or render was run for this compression.
- Manifest content changes only in `performance.fileBytes`. All 121 colliders, 12 hotspots, 30 navigation nodes, 11 rooms, positions and other metadata are preserved.
- The installed Three.js `GLTFLoader` and its bundled `MeshoptDecoder` load both variants with identical attribute/index arrays, names, transforms and material assignments for all 38 meshes.
- Decoding back to a temporary uncompressed GLB produces the exact original GLB SHA-256. All six signage-audit results match `signage-repaired-metrics.json`, including bounds, cap height, triangle counts, clearance, normals and pixel estimates.

## Reproduction and integration

See `assets-src/ASSET_PROVENANCE.md` for complete commands. All Blender exports must be followed by `node assets-src/compress_runtime.mjs` and `python assets-src/validate_manifest.py` before committing. Blender 4.3.2 authoring semantics are unchanged. The MIT encoder is pinned to meshoptimizer 1.1.1 as an explicit development dependency in the sanctioned `web/package.json`, using its already-existing package version and integrity in `web/pnpm-lock.yaml`. No runtime dependency or new package version is introduced. The original compression run reused that exact installed package. The proposed extra tooling manifest was removed because the unchanged repository policy permits only the web manifest; reproduction now uses the normal frozen web install.

Apply the two small edits in `precinct-meshopt-loader.patch` to the current renderer, preserving unrelated changes. `EXT_meshopt_compression` is required; omitting decoder wiring intentionally fails rather than rendering empty geometry. There is no remote/CDN decoder URL.

`validate_manifest.py` uses Node through a fixed `/usr/bin/env node` command on the project's macOS/Linux authoring hosts. It checks the unchanged 5 MiB cap and invokes the actual decoder, verifies every source-view hash, full binary and scene metadata hashes, source hash, real index ranges/finite positions, triangle count and navigation. No new gate suppression or exemption is introduced. It requires web dependencies installed but does not require the encoder package just to validate.

`audit_signage.py` rejects compressed input. Decode first to a **new temporary path outside the repository**, using `node assets-src/decode_runtime.mjs --output /tmp/precinct-audit.glb`, then run the audit on that file. The decoder refuses to overwrite an existing output. Do not commit the decoded copy: it exceeds the size cap. `precinct-compression-signage.json` records this temporary decoded audit, not runtime file size.

## Primary sources and provenance

- [Khronos EXT_meshopt_compression specification](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Vendor/EXT_meshopt_compression/README.md): required extension, placeholder fallback buffer and codec semantics.
- [meshoptimizer JavaScript API](https://github.com/zeux/meshoptimizer/blob/master/js/README.md): `encodeGltfBuffer`, explicit v0 for EXT compatibility. This pipeline uses `ATTRIBUTES` and `INDICES` modes with `NONE` filtering to retain exact bytes.
- [meshoptimizer 1.1.1 npm release](https://www.npmjs.com/package/meshoptimizer/v/1.1.1): pinned authoring tool, MIT, Arseny Kapoulkine. Full notice in `assets-src/MESHOPT_LICENSE.txt`; package integrity is recorded in `web/pnpm-lock.yaml`.
- Installed Three.js 0.186.1 source: `examples/jsm/loaders/GLTFLoader.js` and `examples/jsm/libs/meshopt_decoder.module.js`, already part of the application's dependency tree.
